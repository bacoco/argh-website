Le problème n’est pas le plateau vide, c’est le mot écrit dessus. « Rien » sert à la fois pour une réserve épuisée et pour une porte qu’on n’a pas pu ouvrir. Celui qui lit l’ardoise ne peut plus faire la différence.L’état de disponibilité est effacé à la frontière API, rendant unknown indistinguable de empty. Le type de retour n’offre aucun canal pour cette information, si bien que l’aplatissement se produit avant tout consommateur.The trouble is not the empty tray, it is the word written on it. “Nothing” covers both a pantry that ran out and a door nobody could open. Whoever reads the board can no longer tell them apart.Availability state was erased at the API boundary, making unknown indistinguishable from empty. The return type offers no channel for that information, so the flattening happens before any consumer sees it.
