La retirer ne masque pas un détail, elle retire une décision.Dans un système d’agents, le schéma est une surface exécutable et non un format d’affichage. Retirer un champ peut retirer, avec l’information, la décision que le modèle prenait à partir d’elle.A box on a slip is not only something to read: it is a choice the cook is able to make. Take it away and you have hidden no detail, you have removed a decision.In an agent system the schema is an executable surface, not a display format. Removing a field can take with it the decision the model used to make from that field.
