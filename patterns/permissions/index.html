Signer un geste anodin, en accorder un autreLe prompt mettait en avant le segment anodin d’une commande composéeThe slip names the harmless half onlyThe prompt foregrounded the harmless segment of a composed command

Chez Claude Code, on tend un papier à signer avant d’agir. Il annonce un geste sans conséquence : passer d’une pièce à l’autre. Dans le même mouvement, un second geste engage vraiment la maison, et le papier ne le nomme pas. On signe la première ligne, on accorde la seconde.Sur des commandes shell composées, le prompt de permission de Claude Code pouvait mettre en avant un changement de répertoire anodin tandis que l’opération Git significative restait masquée derrière. L’utilisateur validait un libellé sans rapport avec l’autorité réellement accordée. Un correctif structurel a amélioré la segmentation et la priorité des règles de refus ; une récidive côté affichage a suivi. Cette récidive établit que la correction du parsing et la sémantique d’approbation sont deux problèmes distincts.At Claude Code a slip comes up for signing before anything is done. It names a harmless move: step from one room into the next. Riding with it is a second act that truly binds the house, and the slip never says so. The signature covers the line you read, not the one you gave away.On composed shell commands, Claude Code’s permission prompt could foreground an innocuous directory change while the meaningful Git operation stayed hidden behind it. The user approved a label unrelated to the authority actually granted. A structural fix improved segmentation and deny-rule precedence, and a later display-side recurrence followed. That recurrence is the evidence that parser correctness and approval semantics are two separate problems.

Le geste qui engage la maison n’apparaît pasSignauxThe binding move never reaches the slipSignals

Le papier nomme toujours le plus petit des gestes demandés. Le geste qui engage la maison n’y figure nulle part. Et il revient à chaque service, identique, sans qu’on puisse jamais l’inscrire une fois pour toutes sur la liste des accords.Trois signes suffisent. Le libellé soumis nomme un segment à faible risque d’une opération composée ; l’action de plus haute autorité contenue dans la même opération n’apparaît pas ; le prompt se répète sans qu’aucune règle d’autorisation durable puisse le couvrir utilement. La répétition n’est pas une gêne d’ergonomie, c’est le symptôme que la décision porte sur le mauvais objet.The slip always names the smallest of the moves being asked for. The move that binds the house appears nowhere on it. And it comes back every service, word for word, so it can never be put on the standing list of things already agreed.Three signs are enough. The submitted label names a low-risk segment of a composed operation; the highest-authority action inside that same operation is absent from the label; and the prompt repeats without any durable allow rule being able to cover it usefully. The repetition is not an ergonomic annoyance, it is the symptom that the decision is bound to the wrong object.

La maison découpe bien, puis annonce le mauvais gesteMécanismeThe mistake is which move goes on the slipMechanism

La maison a raison de découper la demande en gestes séparés : c’est ce qu’il faut faire. L’erreur vient d’après, quand elle choisit lequel écrire sur le papier. Elle retient le plus inoffensif, et c’est celui-là qu’on lit. Le client accorde ce qu’il lit, pas ce qui suit.Le parser peut être syntaxiquement correct alors que l’interface retient un segment à faible risque comme action représentative. La tromperie tient à ce que la décision est réelle et appliquée : seule sa description est fausse. La répétition du prompt empêche par ailleurs toute mise en liste blanche utile, ce qui pousse à approuver plus vite et plus large.Splitting the request into separate moves is right, and the house does it properly. The mistake comes one step later, in picking which move goes on the slip. It picks the most harmless one, and that is the one anybody reads. What is granted is what was read, never what came after.A parser can be syntactically correct while the interface still picks a low-risk segment as the representative action. What makes it deceptive is that the decision is real and enforced: only its description is wrong. The repeated prompt also blocks any useful allow-listing, which pushes users to approve faster and broader.

Écrire sur le papier le geste le plus lourdRéponsePrettier wording repairs nothing while the slip liesResponse

Sur le papier, on écrit ce que la demande fait en entier, et d’abord le geste le plus lourd qu’elle contient. Le premier geste venu ne représente rien. Tant que le papier ment, soigner sa présentation ne répare rien : c’est la demande elle-même qu’il faut décrire.Un prompt de permission doit résumer l’effet sémantique de la commande complète et afficher l’action de plus haute autorité qu’elle contient. Le premier segment parsable n’est pas un candidat acceptable pour représenter la décision. La récidive après le correctif structurel situe le travail restant dans la correction de l’enforcement, non dans sa présentation.The slip must say what the whole request does, and lead with the heaviest act inside it. Whichever move comes first stands for nothing. While the slip lies, tidying how it looks fixes nothing; what has to be described is the request itself.A permission prompt must summarise the semantic effect of the whole command and display the highest-authority action it contains. The first parsable segment is not an acceptable candidate to represent the decision. The recurrence after the structural fix places the remaining work inside enforcement correctness, not inside its presentation.

Le plus gros geste passe sans être demandéLeçonThe biggest act goes through unaskedLesson

On n’accorde jamais que ce qui est écrit sur le papier qu’on signe. Si le papier nomme le plus petit geste, le plus grand passe sans avoir été demandé à personne.Approuver la mauvaise description n’est pas une approbation éclairée. L’accord ne couvre que ce que le libellé énonce, indépendamment de ce que le système exécute ensuite.A signature covers the words on the slip and nothing else. Name the smallest move there and the biggest one goes through without ever having been asked for.Approving the wrong description is not informed approval. Consent extends only as far as the label states, regardless of what the system then executes.
