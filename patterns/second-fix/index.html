La caisse change d’étiquette entre les deux portesMécanismeA crate changes label between the two doorsMechanism

On rebouche là où on a vu le désordre, parce que c’est là qu’on l’a vu. Cet endroit est rarement celui où la marchandise devient impossible à ressortir. Entre les deux, une caisse change d’étiquette, et le contrôle d’entrée la laisse passer en toute bonne foi.Le premier modèle mental suppose que l’identité observée près de l’ingestion est celle qui atteindra l’effet final. Une transformation intermédiaire peut modifier cette classification, si bien qu’un filtre amont correct manque quand même l’écriture finale. La tromperie est que le premier correctif est réellement efficace sur ce qu’il mesure : le volume baisse, le vert revient, et la frontière fautive n’a pas été touchée.You seal the spot where you saw the mess, because that is where you saw it. That spot is rarely the one past which goods can no longer be taken out. In between, a crate changes label, and the door check waves it through in good faith.The first mental model assumes the identity observed near ingestion is the one that will reach the final effect. An intermediate transformation can change that classification, so a correct upstream filter still misses the final write. The deception is that the first fix genuinely works on what it measures: volume drops, green returns, and the faulty boundary was never touched.

Contrôler à la porte après laquelle rien ne ressortRéponseCheck at the door past which nothing returnsResponse

Quand le même désordre revient deux fois, cesse de reboucher là où tu l’as vu. Va à la dernière porte, celle après laquelle la marchandise ne ressort plus, et contrôle là. Attache aussi le coup d’œil qui dit « tout est bon » à ce qui travaille vraiment : le fourneau allumé, pas l’écriteau accroché dessus. Ce que tu laisses hors de ce coup d’œil pourra le rendre faux une fois de plus.Quand un correctif échoue deux fois, cesser de patcher la représentation vue en premier et déplacer le garde là où l’effet irréversible se produit, chez Codex le sink de persistance. Indexer de même un état de santé sur les dimensions d’identité qui déterminent l’exécution réelle : exécutable, contexte d’authentification, workspace ou provider selon le cas, comme l’a fait le second correctif chez gstack. Toute dimension exclue de cette clé reste une source possible de faux vert.When the same mess comes back twice, stop sealing the spot where you saw it. Walk to the last door, the one past which nothing comes out again, and check there. Tie the glance that says “all good” to what is actually working: the lit stove, not the sign hung on it. Whatever you leave outside that glance can make it lie once more.When a fix fails twice, stop patching the representation seen first and move the guard to where the irreversible effect happens, at Codex the persistence sink. Index health state likewise on the identity dimensions that determine real execution: executable, authentication context, workspace or provider as applicable, as the second gstack fix did. Any dimension left out of that key remains a possible source of false green.

Réparé veut dire quatre choses différentesLeçonFour different things can be called repairedLesson

La récidive apprend plus que la première réparation : elle montre la porte qu’on avait mal choisie. Et « réparé » n’est jamais un seul mot : écrit, envoyé, rangé, vraiment suivi, chez Codex comme chez Archon, Claude Code ou Gemini.Un second correctif est une preuve causale : l’échec d’une première réparation incomplète localise le mécanisme ou la frontière réellement fautive. Il n’autorise pas pour autant à confondre les états de livraison — correctif source, code mergé, release, artefact installé, récupération observée — que plusieurs lineages indépendantes chez Codex, Archon, Claude Code et Gemini CLI ont montrés distincts.A second round teaches more than the first repair: it shows which door was wrongly chosen. And “repaired” is never one word: written, sent out, put away, actually followed — at Codex as at Archon, Claude Code or Gemini.A second fix is causal evidence: the failure of an incomplete first repair locates the mechanism or boundary actually at fault. It does not license collapsing delivery states — source fix, merged code, release, installed artifact, observed recovery — which independent lineages at Codex, Archon, Claude Code and Gemini CLI showed to be distinct.
