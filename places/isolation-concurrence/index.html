SWE-agent a mis deux cuisiniers sur une ardoiseUn contrôle sûr en exécution sérielle a corrompu son état en exécution parallèleSWE-agent gave two cooks one slateA check that was safe when runs were serial corrupted its state once runs overlapped

Au passe de SWE-agent, il y a une ardoise et une craie. Le cuisinier y écrit sa table et le plat qu’il monte, puis il efface en envoyant. Tant qu’il travaillait seul, la ligne était toujours la sienne. Le jour où ils ont été deux à écrire dessus, un plat est parti à la mauvaise table.Un contrôle conservait, pour chaque exécution, les conditions d’environnement et les données du problème dans des champs ordinaires d’une instance unique. Sous exécution parallèle, deux exécutions partageaient cette instance et pouvaient s’écraser mutuellement. Des sorties ont pu être enregistrées sous le mauvais dossier de problème.SWE-agent keeps one slate at the pass and one stick of chalk. A cook writes his table and his dish on it, then wipes the line when the plate goes out. Working alone, he never read anything but his own handwriting. Put a second cook on the same slate and a plate leaves for the wrong table.A check stored per-run environment conditions and problem data in ordinary fields on a single shared instance. Once runs overlapped, two of them shared that instance and could overwrite each other’s values. Outputs could be recorded against the wrong problem directory.

La consigne de gstack commandait le service suivantUn verrou de débogage prévu pour une session a survécu en état global à la machinegstack left a repair note pinned after closingA debugging lock scoped to one session survived as machine-wide state

Chez gstack, une consigne de dépannage restait punaisée au mur une fois le service terminé. Elle disait « la réserve du fond » sans préciser dans quelle maison. Le lendemain, dans une autre cuisine, les mêmes mots désignaient une autre réserve et bridaient une brigade qui n’avait rien demandé.gstack conservait dans un état global à la machine la frontière d’édition d’un mode de débogage, exprimée en chemin relatif et jamais effacée. Résolue plus tard depuis un autre répertoire de travail, cette même valeur désignait une autre zone et contraignait des sessions sans lien avec celle qui l’avait posée.gstack pinned a troubleshooting note at the station and nobody took it down at closing time. The note named a shelf, but not the room it belonged to. On the next service, in another room, the same note fenced in a crew that had never asked for it.gstack kept a debugging mode’s edit boundary in machine-global state, expressed as a relative path and never cleared. Resolved later from a different working directory, that single stored value designated a different area and constrained sessions unrelated to the one that set it.

Tant qu’un seul commis travaillait, le billot commun suffisait. À plusieurs en même temps, les préparations se mélangent. Codex, gstack, Claude Code et Cline en viennent tous à donner un plan de travail par commis. Les quatre maisons n’en sont pas au même point.Les worktrees et mécanismes équivalents d’isolation passent de discipline développeur à infrastructure gérée par le runtime, à mesure que l’exécution parallèle devient normale. Codex, gstack, Claude Code et Cline suivent la même trajectoire, à des niveaux de maturité différents.While one cook worked alone, the shared bench was enough. Put several on it at once and the preparations run together. Codex, gstack, Claude Code and Cline all end up handing out one bench per cook. The four houses are not equally far along.Worktrees and equivalent isolated-workspace mechanisms are moving from developer discipline into runtime-managed infrastructure as parallel execution becomes normal. Codex, gstack, Claude Code and Cline follow the same trajectory at different maturity levels.

Avec MCP, le plat changeait de tableUn état de connexion global et mutable pouvait faire livrer un message à la mauvaise sessionAn MCP plate could reach the wrong tableShared mutable connection state could deliver a message to the wrong session

Chez les maisons qui travaillent avec MCP, une seule fiche sur le comptoir indique la table qu’on sert. Chaque nouvelle arrivée remplace la fiche par la sienne. Le commis, lui, ne lit la fiche qu’au moment de partir. Un plat commandé par la table d’avant pouvait donc s’en aller vers celle d’après.Un état de connexion partagé et mutable permettait à une session ultérieure de remplacer la connexion globalement courante. Une notification émise ensuite pour la première session pouvait donc emprunter la connexion d’une autre.In the houses that work with MCP, one card on the counter says which table is being served. Every new party that sits down replaces it. The runner only reads the card at the moment he leaves the pass. So a plate ordered by the earlier table could walk out to the later one.Shared mutable connection state let a later session replace the globally current connection. A notification raised afterwards for the first session could then ride another session’s connection.

Chez Codex, un billot pour plusieurs commisL’allocation de worktrees est entrée dans le chemin d’exécution, à titre expérimentalCodex cooks kept colliding on one shared benchWorktree allocation entered the execution path, as an experimental feature

Chez Codex, avec un seul commis, partager le billot ne gênait personne. Dès qu’ils ont travaillé à plusieurs en même temps, les préparations se sont mélangées. La maison a commencé à attribuer un billot par commis. Ce n’est pas encore la règle partout : c’est un essai en cours.L’allocation gérée de worktrees est entrée dans le chemin d’exécution des sessions CLI. L’isolation du workspace devient ainsi une capacité de première classe du harnais plutôt qu’une convention appliquée par l’utilisateur. La fonctionnalité est explicitement expérimentale ; rien n’établit qu’elle soit devenue le comportement par défaut.One cook on a shared bench bothered nobody at Codex. Put several on it at once and the preparations run into each other. So the house started handing out a bench per cook. It is not yet how every service runs — it is a trial.Managed worktree allocation moved into the execution path of CLI sessions. Workspace isolation thereby becomes a harness capability rather than a convention users are expected to apply themselves. The feature is explicitly experimental, and nothing establishes it as the default.
