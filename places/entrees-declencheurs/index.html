Le client signe pour un geste, la cuisine en fait un autreLe prompt de permission demandait un accord — pour la mauvaise actionThe diner signs for one move and the kitchen makes anotherThe permission prompt asked for approval — for the wrong action

Une commande arrive en plusieurs gestes annoncés d’une traite. Avant de commencer, la cuisine tend une feuille au client. Elle montre le geste anodin, tandis que le plus lourd attend derrière. Le client signe donc pour autre chose que ce qui sera fait.Sur des commandes shell composées, le prompt de permission pouvait mettre en avant un changement de répertoire anodin tandis que l’opération Git significative restait masquée derrière. L’utilisateur validait alors un libellé sans rapport avec l’autorité réellement accordée.An order arrives as several moves called in one breath. Before starting, the kitchen sends the diner a slip. It shows the harmless move while the heavier one waits behind it. The signature therefore covers something other than what will happen.With compound shell commands, the permission prompt could foreground a harmless directory change while the meaningful Git operation stayed hidden behind it. The approval then granted authority that the displayed label did not describe.
