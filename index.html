Les plis sont scellés, le carnet de service se videLe chiffrement entre subagents a gagné en confidentialité et perdu en auditabilitéSealed notes leave the service book blankEncryption between subagents gained confidentiality and lost auditability

Pour éviter les regards indiscrets, les sous-chefs s’écrivent sous pli fermé. Seul le destinataire peut lire la consigne. Le chef ne le peut pas davantage que les autres. Le carnet de service ne garde donc plus aucune trace de ces échanges.Le chiffrement des communications agent-à-agent a protégé la confidentialité des destinataires. Il a aussi retiré de l’historique normal du parent les traces lisibles des tâches et des messages, supprimant le support sur lequel les opérateurs s’appuyaient.To stop prying eyes, the sous-chefs write to each other in sealed notes. Only the named recipient can read an instruction. The head chef cannot read it either. The service book therefore keeps no trace of those exchanges.Encrypting agent-to-agent communication protected recipient confidentiality. It also removed readable task and message traces from the parent’s normal history, eliminating the support operators relied on.

La confiance se donne à toute la cuisine d’un seul gesteUne seule décision de confiance couvre hooks, serveurs MCP et fichiers d’instructionsTrust covers the whole kitchen or none of itA single trust decision covers hooks, MCP servers and instruction files

Vous entrez dans une cuisine inconnue. Des consignes couvrent le mur, des outils attendent sur le billot et des caisses arrivent par la porte. Ces trois choses peuvent orienter le service sans prévenir. La maison les accepte ou les écarte donc ensemble.Le modèle de confiance de Gemini CLI désactive ensemble les hooks projet, les serveurs MCP et les fichiers d’instructions dans les dossiers non fiables. Les trois sont traités comme une même classe d’influence exécutable, et non comme trois sous-systèmes indépendants.You enter an unfamiliar kitchen. Instructions cover the wall, tools wait on the bench, and crates arrive through the back door. All three can steer service without warning. The house therefore accepts or refuses them together.Gemini CLI’s trust model disables project hooks, MCP servers and instruction files together in untrusted folders. All three are treated as one class of executable influence rather than three independent subsystems.

The real launch path then dropped the significant option, downstream of everything the test observed. The resulting green measured confidence, not end-to-end coverage.

Un poste hérite du bon de contrôle d’un autreUn false-green corrigé, puis reproduit sur une autre dimension d’identitéOne ready slip is reused for two stationsA false green was fixed, then recurred on a different identity dimension

Un matin, quelqu’un vérifie un poste et accroche le bon « prêt pour le service ». Le lendemain, un poste ressemblant reçoit ce même bon sans contrôle. Le billot paraît identique, mais le four et les clés diffèrent.Un état de santé en cache déclarait l’environnement utilisable alors que le chemin réel échouait. Un premier correctif a traité l’incompatibilité observée ; une incompatibilité d’identité structurellement similaire a ensuite reproduit le même faux vert. Le second correctif a élargi la clé de cache vers l’exécutable et le contexte d’authentification réel.One morning, someone checks a station and hangs a ready-for-service slip. The next day, a similar station inherits that slip without inspection. The bench looks alike, but the oven and pantry keys differ.Cached health state reported a usable environment while the real path failed. A first repair closed the observed mismatch, and a structurally similar identity mismatch then reproduced the same false green. The second repair widened the cache key toward the executable and the real authentication context.
